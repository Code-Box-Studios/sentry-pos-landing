# Glossary

[Guide home](README.md) · [Feature index](feature-index.md)

| Word | Meaning in Sentry |
| --- | --- |
| Account / owner account | The owner's platform access and the businesses under it. |
| Active | Account/staff access status that permits use when required credentials are complete. |
| Adjustment | A stock correction entered with a reason; it changes quantity and records a movement. |
| Approval | A manager/owner PIN entered in person to authorize one protected cashier action. It does not switch operator. |
| Audit / activity log | Recorded events describing who did an action, when, and what changed. |
| Batch | A received group of stock with remaining quantity and, where tracked, an expiry date. |
| Blind close | A closing process that hides expected cash before the operator submits their count. |
| Branch | One location of a business, with its own stock and assigned terminals. |
| Business | One organization/catalog/settings scope under an owner. |
| Business-day cutoff / day start | Configured time when one trading/reporting day rolls into the next. |
| Cash in / cash out | Drawer cash added/removed outside sales, recorded with a reason. |
| Cash variance / over-short | Counted closing cash minus expected closing cash. Positive is over; negative is short. |
| Catalog | Products, categories, variants, modifiers and named discounts available to a business. |
| Category | A group used to organize products. |
| Centavos | One hundredth of a peso. 100 centavos = ₱1.00; some admin inspector amounts use this unit. |
| CMS | The separate website content editor at `/cms`. |
| Cost | Recorded unit purchase cost used for stock valuation and profit reporting. |
| Count / stocktake | Draft physical shelf quantities which, when posted, generate stock adjustments. |
| Demo business | A sample business for practice, excluded from ordinary combined owner reporting. |
| Discount, named | An owner-configured promotion staff select from the available list. |
| Drawer / shift | One named operator's cash session on a terminal, from opening float to closing count. |
| FEFO | First expiry, first out: earlier-expiring batches are consumed first where expiry is tracked. |
| Float / opening cash | Cash already in the drawer at the start of a shift. |
| Gross profit | Sales less the recorded cost of sold items, under the report's rules; missing cost data affects it. |
| Held cart | An unpaid order saved for resuming later on the terminal. It is not a paid sale. |
| Hard suspension | Immediate platform access block that includes terminals mid-shift. |
| Low-stock threshold | Quantity level at which stock is considered low. |
| Misc item | A manually entered sale line available through POS; it is not a new catalog product. |
| Modifier | A selectable add-on/option, such as extra milk, grouped for use with products. |
| Operator | The named owner, manager or cashier currently unlocked on a terminal. |
| Pairing | Connecting a browser/device identity to a specific branch terminal using owner authorization. |
| Pending staff | Someone who must complete first-time setup or a credential reset before active use. |
| Pending payment | A saved submitted payment attempt whose result must be resolved/retried. |
| PIN | Six-digit terminal credential, distinct from a portal password. |
| Portal | Owner/manager/admin browser screens for management and reporting. |
| Receipt number | The identifier for a completed sale, useful for history, reprint and reconciliation. |
| Recovery code | An admin's one-use alternative to an authenticator code. |
| Refund | A recorded full-sale reversal under the app's eligibility/approval rules. Money-provider reversal is separate. |
| SC / PWD | Senior citizen / person with disability; POS supports dedicated discount/tax treatment. |
| Service charge | Business-configured surcharge applied to eligible dine-in orders. |
| SKU | A store's stock/product identifier; distinct from the scannable barcode. |
| Stock movement | A record of quantity changing through receiving, sales, correction, transfer or count posting. |
| Suspension | Portal access block with a limited grace for already open terminal shifts. |
| Temporary PIN | One-use setup/reset challenge, expiring after 15 minutes. |
| Terminal | One paired counter browser, identified by name/code and associated with a branch. |
| TOTP / authenticator | Time-based code used as the platform admin's second sign-in factor. |
| Transfer | Moving stock between two branches of the same business. |
| Variant | A sellable version of a product, such as size; price/barcode/stock may be variant-specific. |
| VAT | Value-added tax as represented by the configured business and POS calculation. |
| Void | Reversal of an eligible completed sale, with reason/approval under the current shift rules. |
| Z report | The closing report for a shift, including sales/payment/cash information. |
